### 🛠️ 如何创建自定义 Skill？

创建 Skill 主要有**独立配置**和**插件（Plugin）** 两种方式。

#### 方式一：独立配置（推荐入门）

这是最直接的方式，适合个人工作流或项目内快速实验。

1. **确定存放位置**：在项目根目录下创建文件夹 `.claude/skills/`。
    
2. **创建 Skill 文件夹**：在 `.claude/skills/` 下，为你的 Skill 创建一个专门的文件夹，例如 `my-first-skill`。
    
3. **编写核心文件**：在 `my-first-skill` 文件夹中，创建一个名为 `SKILL.md` 的文件。
    

#### 方式二：通过插件（Plugin）共享

当你需要**与团队共享**、**跨项目复用**，或**发布到社区**时，可以将 Skill 打包成插件。

- 插件需要有一个 `plugin.json` 清单文件来定义其元数据（名称、版本等）。
    
- 插件中的 Skill 调用时会带上**命名空间前缀**（如 `/my-plugin:hello`），以避免名称冲突。
    

### 📝 `SKILL.md` 文件怎么写？

`SKILL.md` 是 Skill 的核心，结构清晰是关键。它通常包含以下三层结构[](https://cloud.tencent.com.cn/developer/article/2698677?policyId=1004#1)：

- **元数据层 (Frontmatter)**：文件开头的 YAML 格式数据，用于声明 Skill 的**名称**和**描述**。Claude 会根据这里的描述来判断何时该调用此 Skill[](https://cloud.tencent.com.cn/developer/article/2698677?policyId=1004#1)。
    
    yaml
    
    ---
    name: my-first-skill
    description: 在这里清晰描述这个技能是做什么的，Claude会根据这个描述来判断何时使用。
    ---
    
- **指令层 (Instructions)**：这是 Markdown 正文，告诉 Claude **具体该怎么做**。可以包含步骤、规则、约束条件和期望的输出格式[](https://cloud.tencent.com.cn/developer/article/2698677?policyId=1004#1)。
    
- **资源层 (Resources)**（可选）：如果指令很复杂，你可以在 Skill 文件夹下创建 `scripts/`、`references/` 等子文件夹来存放支撑脚本或参考文档，供 Claude 按需读取[](https://cloud.tencent.com.cn/developer/article/2698677?policyId=1004#1)。
    

### 🚀 如何调用与测试？

- **手动调用**：在 Claude Code 的对话中，直接输入 `/my-first-skill`。
    
- **自动调用**：Claude 会根据 `SKILL.md` 中的 `description` 元数据，自主判断在相关任务中是否启用该 Skill。
    
- **测试插件**：如果创建的是插件，可以使用 `--plugin-dir` 标志来指向插件目录进行本地测试。
    
- **浏览管理**：在 REPL 中输入 `/skills` 命令，可以打开交互式浏览器，查看所有可用的 Skills。
