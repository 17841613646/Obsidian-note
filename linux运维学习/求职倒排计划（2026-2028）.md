## 2. 本学期详细计划（2026.09.13 – 2027.01，约 18 周 ≈ 360 小时）

### 📅 阶段 A｜Linux 命令核心（第 1–4 周，9 月中 – 10 月中）

**要学：**
- 目录与文件：`ls` `cd` `pwd` `mkdir` `rmdir` `touch` `cp` `mv` `rm` `ln`（硬链接 vs 软链接）
- 看文件：`cat` `less` `more` `head` `tail` `wc` `nl` `file`
- 查找：`find`（按名/时间/大小/权限）`which` `whereis` `locate`
- 压缩打包：`tar`（重点，面试常考那几个参数）`gzip` `zip/unzip`
- **权限（重中之重）**：`chmod` 数字法与符号法、`chown` `chgrp`、`umask`、特殊权限 SUID/SGID/粘滞位
- **用户与组**：`useradd` `usermod` `userdel` `groupadd` `passwd` `id` `su` `sudo`
- 理解 `/etc/passwd`、`/etc/shadow`、`/etc/group` 三个文件各存什么

**✅ 验收标准（达不到就重学）：**
1. 能给别人讲清楚 `-rwxr-xr--` 每一位是什么意思，以及对应的数字是多少
2. 给你一台陌生机器，15 分钟内建好一个用户 → 给他 sudo 权限 → 建一个共享目录，让两个用户都能读写、但别人删不掉里面的文件
3. 能解释**为什么密码不能存在 /etc/passwd 里，要单独放 /etc/shadow**

---

### 📅 阶段 B｜进程 / 服务 / 包管理 / Vim（第 5–6 周，10 月中 – 10 月底）

**要学：**
- 进程：`ps aux` `top` `htop` `pgrep` `kill` `killall` `nice` `renice`、前台/后台 `&` `jobs` `fg` `bg` `nohup`
- 服务：`systemctl`（start/stop/restart/status/enable/disable）、理解 Unit 文件
- 日志：`journalctl`（-u / -f / --since）、`/var/log/` 目录
- 包管理：`dnf`（install/remove/search/info/history）、`rpm -qa`、`dnf provides`
- 编辑器：Vim（模式切换、移动、删除、复制粘贴、查找替换、保存退出）

**✅ 验收标准：**
1. 能查出一个吃 CPU 最高的进程，说出它的 PID 和父进程，然后干掉它
2. 能把一个服务设成开机自启、重启验证、并只看它最近 10 分钟的错误日志
3. 能用 `dnf history` 回滚一次误装
4. Vim 里能不碰鼠标完成：跳到最后一行 → 全局替换一个词 → 保存退出

> 💡 小提示：`htop` 和 `tree` 需要 `dnf install` 才能用，装一次顺便练包管理。

---

### 📅 阶段 C｜文本三剑客 + Shell 脚本（第 7–9 周，11 月）

**为什么这是分水岭：** 会敲命令的人是"操作工"，会写脚本的人才是"运维"。

**要学：**
- `grep`：正则、`-i` `-v` `-r` `-n` `-E`、配合管道
- `awk`：按列取、条件过滤、求和统计（分析日志的主力）
- `sed`：替换、删除行、按范围操作
- 管道与重定向：`|` `>` `>>` `2>` `&>` `tee`、`$?` `&&` `||`
- Shell 脚本：变量与引号（单双引号区别是面试题）、`if` `case`、`for` `while`、函数、位置参数 `$1` `$#` `$@`
- 定时任务：`crontab`（五个星号分别代表什么，必背）
- `curl` 与 `wget`（调接口、下载）
- 软技能：`vim ~/.bashrc` + 别名 alias + 环境变量 PATH

**✅ 验收标准（这是本学期的第一个项目产出）：**
> 写一个 **日志自动清理 + 备份 + 失败告警** 的脚本：
> - 找出 /var/log 下 7 天前的日志，压缩归档到备份目录
> - 归档后删除原文件
> - 整个过程的每一步都写日志
> - 任何一步失败，脚本返回非 0 并且打印错误原因
> - 挂到 crontab 上，每天凌晨 3 点自动跑
>
> **这个脚本可以直接写进简历。** 面试官问"你写过什么脚本"，你就有话讲。

---

### 📅 阶段 D｜网络基础（第 10–13 周，11 月下 – 12 月中）

**跟课内《计算机网络》同步学，事半功倍。**

**要学：**
- OSI 七层 vs TCP/IP 四层（能背出每层干什么、有哪些协议）
- TCP：三次握手、四次挥手、为什么是三次不是两次（**必考**）
- TCP vs UDP：各自适用场景
- IP 与子网：子网掩码、CIDR、网段、网关、广播地址（**能算**）
- 路由：路由表怎么看，静态路由怎么加
- DNS：解析全过程（递归 vs 迭代）、A/AAAA/CNAME/MX/NS 记录
- ARP 与 MAC 地址、交换机与路由器的区别
- HTTP/HTTPS：请求方法、状态码（2xx/3xx/4xx/5xx 各举几个）、常见头部字段
- 抓包：`tcpdump` 和 Wireshark，能看懂一次 HTTP 请求的完整过程

**✅ 验收标准：**
1. 能用 `tcpdump` 抓一次你自己网站的 HTTP 请求，并逐步解释每个包在干什么
2. 给你 `192.168.10.0/26`，能算出网段、可用主机范围、广播地址
3. 能讲清楚：在浏览器输入网址到页面出来，中间发生了什么（**经典面试题，必须能讲 3 分钟**）

---

### 📅 阶段 E｜真实部署（第 14–18 周，12 月中 – 2027.01）

**本学期的大产出：把一个网站真正放到公网上。**

**要学：**
- 防火墙：`firewalld`（zone / 开放端口 / 富规则）与 `iptables` 基础
- SELinux：三种模式、为什么刚配好的 Nginx 访问不了（**90% 新手卡在这里**）
- Nginx：安装、配置文件结构、虚拟主机、反向代理、静态资源
- MySQL：安装、`mysql_secure_installation`、建库建表、用户授权、基本 CRUD
- 域名与 DNS：解析记录怎么配（A 记录指向服务器 IP）
- HTTPS：`Let's Encrypt` + `certbot` 免费证书，自动续期

**✅ 验收标准（本学期的最终交付物）：**

> **手机上打开你的域名，能看到你的个人博客，地址栏有 HTTPS 小锁，证书是自动续期的。**

拿到这个，你简历上就有第一行真东西了：

```
个人站点    2026.12 – 2027.01
· 在云服务器上基于 Nginx 部署个人博客，配置域名解析与 Let's Encrypt 自动续期 HTTPS
· 通过 firewalld 配置端口策略，排查并解决 SELinux 导致的 Nginx 静态资源 403 问题
· 使用 MySQL 存储博客数据，编写 Shell 脚本实现日志自动清理与备份（crontab 定时执行）
```

**这就是面试官会追问的三行字。** 比"熟悉 Linux 常用命令"强一百倍。

## 3. 寒假（2027.01 – 02）：Docker 完整掌握

**要学：**
- 三个核心概念：镜像 / 容器 / 仓库（用"集装箱"的比喻理解）
- 常用命令：`docker run` `ps` `images` `exec` `logs` `stop` `rm` `rmi` `pull` `push`
- Dockerfile：`FROM` `RUN` `COPY` `WORKDIR` `EXPOSE` `CMD` `ENTRYPOINT`，多阶段构建
- 数据持久化：数据卷 volume 与 bind mount 的区别
- 网络：bridge / host / none、容器间怎么互相访问
- Docker Compose：用一份 YAML 编排多容器
- 镜像仓库：Docker Hub、阿里云容器镜像服务、私有仓库

**✅ 验收标准：**
> 用 `docker compose up -d` 一条命令，起一套 **Nginx + 应用 + MySQL + Redis** 的完整环境，并且：
> - 数据在容器删掉重建后不丢（volumes）
> - 自己写 Dockerfile 构建过一个镜像并推到镜像仓库
> - 能用 `docker logs` 和 `docker exec` 定位一个容器为什么起不来

## 6. 服务器与域名

> **当前决定：本学期不自己花钱买服务器。** 先在本地虚拟机上把阶段 A–D 练完，同时去申请**学生机**（阿里云"高校计划" / 腾讯云"云+校园"，需**学信网学籍在线验证报告**做认证——你是在籍本科生，可以正常认证 ✅）。等学生机到手，再办域名和备案。

### 服务器
- **本地虚拟机（现在的主力）**：用来做危险实验（删库、改崩配置、装失败）——有快照，随时回滚。**继续用 Rocky Linux 9**（企业主流，和 RHCSA 对口）。
- **云服务器（等学生机）**：用来练真实部署（公网 IP、域名、HTTPS、远程排查）。配置瞄准 **2 核 4G**，因为后面学 K8s 时 2G 内存会卡死。
- 💡 云服务器系统建议选 **Ubuntu** 或 **Alibaba Cloud Linux**：这样你 **RHEL 系（dnf）+ Debian 系（apt）都摸过**，面试问"两者的区别"你答得出来，这是加分项。

### 域名与备案（重要，别踩坑）
- **已定：买域名 + 走备案**（国内服务器绑域名必须备案，流程约 15–20 天，趁早提交）。
- 备案需要先有服务器和域名，所以顺序是：**学生机到手 → 买域名 → 提交备案 → 部署**。
- 便宜的域名后缀（.top / .xyz）一年几十块，够用。
- 如果实在等不及备案，退路是买 **香港/境外轻量服务器**，免备案，但速度慢、价格略高。

## 7. 面试高频问题（现在就带着这些问题去学）

学每一块内容时，试着回答对应的问题。**能讲明白 = 真会了。**

**Linux 系统**
- 描述 Linux 的启动流程，从按下电源到登录界面发生了什么？
- `/etc/passwd` 和 `/etc/shadow` 为什么要分开？
- 软链接和硬链接的区别？删掉源文件后软链接会怎样？
- 服务器负载高，你怎么排查？（`uptime` → `top` → `iostat` → 定位进程 → 看日志）
- 磁盘满了，怎么快速找到是谁占的？（`df -h` → `du -sh /*` 逐层排查）
- SELinux 是什么？为什么刚配好的服务访问不了？

**网络**
- 在浏览器输入网址到页面显示，中间发生了什么？（**必考，要能讲 3 分钟**）
- TCP 为什么是三次握手？两次行不行？
- 状态码 301 / 302 / 403 / 404 / 502 / 504 分别什么含义？
- 一台机器 ping 不通另一台，你怎么排查？（从物理层往上一层一层排）

**容器与 K8s**
- 容器和虚拟机的区别？
- Docker 镜像的分层是怎么工作的？为什么改一行代码不用重新拉整个镜像？
- K8s 的 Pod / Deployment / Service 各解决什么问题？
- 一个 Pod 一直处于 Pending / CrashLoopBackOff，你怎么查？

## 8. 笔记规范（重要，别让笔记白记）

**目前的问题：** 笔记以"截图 + 一句话"为主。三个月后你会发现：截图里的命令**搜不到、复制不了、看不出自己打错在哪**。

**改进建议：**
1. **命令一律写成代码块纯文本**，图片只用来放架构图、流程图
2. 建一个 `踩坑记录/` 文件夹，每次卡住超过 30 分钟就记一条：
   ```
   ## 现象：Nginx 访问静态文件报 403
   环境：Rocky Linux 9 + Nginx 1.24
   排查过程：
     1. 检查文件权限 → 正常
     2. 检查 Nginx 错误日志 /var/log/nginx/error.log → 看到 "Permission denied"
     3. 怀疑 SELinux → getenforce 返回 Enforcing
   原因：SELinux 不允许 Nginx 读取 /home 下的文件
   解决：chcon -R -t httpd_sys_content_t /home/xxx
   复习：https://...
   ```
   **你踩过的坑，就是面试时最亮眼的回答。** "我遇到过 X，我是这样定位的"比背知识点强十倍。
3. 每条笔记末尾加一行自查：**"不看资料，我能做出来吗？"** 做不到，就说明这篇笔记还没完成。

**铁律：**

- ✅ **每 4 周做一次"盲测"**：合上笔记，把上个月学的验收任务重做一遍
- ✅ 虚拟机**每周打一次快照**，玩崩了就回滚，这样才敢乱搞
