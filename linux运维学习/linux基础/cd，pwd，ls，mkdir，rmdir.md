### 目录导航与管理概述
![[Pasted image 20260913110724.png]]
### 确认当前位置：pwd指令
pwd：print working Director 打印当前工作文件夹
功能：显示当前工作目录的绝对路径

![[Pasted image 20260913110914.png]]

### 绝对路径与相对路径

绝对路径：从根目录到当前目录的完整路径
相对路径：相对于当前目录的路径

![[Pasted image 20260913110950.png]]

### cd的快捷跳转功能

- cd~或cd 快速返回家目录
- cd - 在最近两个目录间切换
- cd ..快速返回上一级目录

![[Pasted image 20260913111546.png]]

### ls及常用选项详解

- -l：显示长信息
- -a：显示隐藏文件
- -h：人类可读单位（kb，MB）

![[Pasted image 20260913120207.png]]

### ls的组合选项使用

ls - lah 详细显示 隐藏文件 文件易读化
ls -lrt  最新修改的文件显示在最下方
- -t：按修改时间排序
- -r：反转排序结果
![[Pasted image 20260913120651.png]]

### 创建新目录：mkdir命令

mkdir 「目录名」

![[Pasted image 20260913122006.png]]


### 递归创建：mkdir -p

- 普通创建文件夹时父目录不存在会报错
- -p   选项：自动补齐中间路径
- 能一次性构建完整目录树

![[Pasted image 20260913122047.png]]

### rmdir：安全删除空目录

- 只能删除空目录
- 能防止误删目录内数据

![[Pasted image 20260913122202.png]]

![[Pasted image 20260913122444.png]]

### 总结
- pwd显示当前工作路径
- cd 切换文件夹
- ls 列出当前目录下文件
- mkdir新建目录
- rmdir删除空目录
