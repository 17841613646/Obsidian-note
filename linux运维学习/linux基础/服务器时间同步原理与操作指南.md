ntp部署
安装
# CentOS/RHEL（红帽系统）
sudo yum install ntp    # 老系统用这个
sudo dnf install ntp    # 新系统用这个

# Ubuntu/Debian（乌班图系统）
sudo apt install ntp    # 会自动配置基础参数

启动校时服务
# CentOS
sudo systemctl start ntpd    # 现在开始工作
sudo systemctl enable ntpd   # 以后开机自动工作

# Ubuntu
sudo systemctl start ntp
sudo systemctl enable ntp

检查校时状态
systemctl status ntpd  # 看到"active (running)"就成功啦！
# 如果显示红色错误，可能是防火墙没开UDP123端口

配置文件（文件位置：/etc/ntp.conf）
# 添加这些"标准钟表"（任选3个即可）
server ntp.aliyun.com iburst    # 阿里云的大钟
server time.apple.com iburst   # 苹果的原子钟
server cn.pool.ntp.org iburst  # 中国的公共校时池

改完配置要重启服务： systemctl restart ntpd
ntpq -p 命令查看 NTP 服务器的同步状态


chrony部署
# CentOS
sudo yum install chrony && sudo systemctl start chronyd

# Ubuntu
sudo apt install chrony && sudo systemctl start chrony

查看校时效果
chronyc tracking  # 看同步状态（像手表上的"已连接"提示）
chronyc sources   # 显示正在用的"参考钟表"

systemctl restart chronyd
