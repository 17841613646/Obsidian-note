# Linux sed 命令终极实战指南

## 一、 核心定义

`sed`（Stream Editor）是 Linux 中最强大的**流编辑器**。它按行读取文件，对匹配的内容进行“增删改查”后输出。**它不直接修改原文件（除非加 `-i`）**，而是将处理后的结果输出到屏幕。

## 二、 基础格式与核心参数

bash

sed [选项] '脚本' 文件名

- **`-i`**：直接修改原文件（**⚠️ 生产环境操作前必须先备份！**）
    
- **`-e`**：指定多个编辑脚本（多条件操作）
    
- **`-E`** 或 **`-r`**：使用扩展正则表达式（支持 `+`, `?`, `{}`, `()` 等）
    
- **`-n`**：取消默认输出（通常配合 `p` 打印命令使用，只打印匹配的行）
    

## 三、 四大核心操作

### 🔄 1. 替换操作（s）

**基础格式：** `sed 's/旧词/新词/标志' 文件名`

- **默认替换**：只替换每行**第一个**匹配项。  
    `sed 's/cat/dog/' file.txt`
    
- **全局替换**：加 `g`。  
    `sed 's/cat/dog/g' file.txt`
    
- **自定义分隔符**：处理路径等含斜杠的内容时，可把 `/` 换成 `#` 或 `|`。  
    `sed 's#/usr/local/bin#/opt/bin#g' paths.txt`
    
- **引用匹配内容**：
    
    - 用 `&` 引用整个匹配项：`sed 's/[0-9]\+/[&]/g'`
        
    - 用 `\1`, `\2` 引用正则捕获组（需配合 `-E`）：`sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/\3\/\2\/\1/'`（日期格式调换）。
        
- **多条件替换**：使用 `-e`。  
    `sed -e 's/苹果/Apple/g' -e 's/香蕉/Banana/g' file.txt`
    

### 🗑️ 2. 删除操作（d）

**基础格式：** `sed '匹配条件/d' 文件名`

- **删除空行**：`sed '/^$/d' file.txt`
    
- **删除包含特定词的行**：`sed '/temp/d' file.txt`
    
- **删除指定行号范围**：`sed '3,5d' file.txt`（删除第 3 到 5 行）。
    
- **删除区间内容**：`sed '/START/,/END/d' file.txt`（删除从 START 到 END 之间的所有行）。
    
- **取反删除（保留包含数字的行）**：`sed '/[0-9]/!d' file.txt`（`!d` 表示删除不匹配的行）。
    
- **删除大文件局部**：`sed '1,1000d' hugefile.log`
    

### 📝 3. 插入与追加（i, a, c）

- **`a` (Append)**：在指定行**后面**追加。
    
    - 文件最后一行追加：`sed '$a 这是追加的内容' file.txt`
        
- **`i` (Insert)**：在指定行**前面**插入。
    
    - 文件开头插入标题：`sed '1i # 这是文件的标题' file.txt`
        
    - 在匹配行前插入空行：`sed '/import/i \' file.txt`
        
- **`c` (Change)**：**替换**整行。
    
    - `sed '/^#Port/c\Port 3222' sshd_config`（替换整行内容）
        

### 🔍 4. 打印操作（p）

- **配合 `-n` 只打印匹配行**：`sed -n '/error/p' log.txt`
    
- **打印指定行号范围**：`sed -n '1,5p' file.txt`
    

## 四、 进阶技巧与条件替换

- **条件替换（行匹配）**：仅替换包含 "error" 的行。  
    `sed '/error/ s/error/ERROR/g' log.txt`
    
- **条件替换（行号匹配）**：从第 5 行开始替换。  
    `sed '5,$ {/error/ s/error/ERROR/g}' log.txt`
    
- **特殊字符转义**：
    
    - `/` 转义为 `\/`（或直接换分隔符）
        
    - `&` 转义为 `\&`
        
    - `\` 转义为 `\\`
        
- **大文件防卡死**：限制处理行数 `sed '1,1000s/old/new/g' hugefile.log`。
    

## 五、 趣味实战（经典一行命令）

**1. 生成8位包含大小写字母+数字的密码**

bash

date | md5sum | sed 's/[^a-zA-Z0-9]//g' | cut -c1-8

_解析：获取当前时间 -> 计算MD5 -> 用 `sed` 删除所有非字母和数字的字符 -> 用 `cut` 截取前8位。_

**2. 随机生成大乐透彩票号码**

bash

echo "$(shuf -i 1-35 -n5 | sed 'N;N;N;N;s/\n/ /g') | $(shuf -i 1-12 -n2 | sed 'N;s/\n/ /g')"

_解析：`shuf` 随机生成5个1-35的号码，`sed 'N;N;N;N;s/\n/ /g'` 将每行用换行符分隔的5个数字合并成一行并用空格隔开（`N` 是将下一行读入模式空间，重复4次就是合并5行）。_

## ⚠️ 运维安全小贴士（必看！）

1. **`-i` 是双刃剑**：`sed -i` 会直接修改原文件。在生产环境修改 `nginx.conf`、`sshd_config` 等核心配置前，**务必先 `cp` 备份**，或者先用不带 `-i` 的命令测试输出是否正确。
    
2. **正则贪婪匹配**：`sed` 默认是贪婪匹配，写复杂正则时要特别注意。
    
3. **与 `grep` 分工**：`grep` 擅长找内容所在行（查看），`sed` 擅长修改/替换（编辑）。两者结合使用威力最大。
