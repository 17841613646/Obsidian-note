
# 用户管理
### 1.1创建新用户的命令

useradd 【选项】 【用户名】
- useradd -m username
- adduser username
### 1.2设置密码的命令

passwd  【选项】 【用户名】
- -l 锁定用户密码
- -u 解锁用户密码
- -e 用户登录后修改新密码

### 1.3设置密码过期时间

chage 【选项】【用户】
- -l 查看该用户密码过期时间
- -E修改账户过期时间
chage -E 2025-02-26 xiaoming


# 用户组管理
### 2.1创建用户组

groupadd 【新用户组】
groupadd  testgroup
创建用户组名为 testgroup的组

### 2.2删除用户组
groupdel 【组名】

groupdel testgroup
删除组名为 testgroup的组

### 查看所有已经创建的用户组

cat /etc/group

### 2.3.1将用户加入用户组(1)

usermod -aG 【组名】 用户
-G<群组>；修改用户所属的附加群组；
把用户加入新组

### 2.3.2将用户加入用户组(2)
gpasswd -a 【用户】 【组名】

### 2.4查看该用户所属组

id -nG 【用户】
-n, --name 打印名称而不是数字
-G, --groups 打印全部组ID。
### 2.5把用户踢出组

gpasswd  【选项】 【用户】 【组名】
-a：添加用户到组；
-d：从组删除用户；

gpasswd -d xiaoming testgroup
把用户xiaoming踢出testgroup组

### 2.6查看组成员

getent group 【组名】


### 2.7添加用户到sudo组
gpasswd -a wheel 【用户】

usermod  -aG【组名】 【用户】


### 💡 运维小贴士

- 创建用户最规范的方式是：
    
    bash
    
    sudo useradd -m -s /bin/bash sky
    sudo passwd sky
    
    `-m` 自动创建家目录，`-s` 指定用 bash。
    
- 你现在正在做 NFS 实验。如果 `sky` 这个用户在两台服务器上都要用，**务必保证两台机器上 `sky` 的 UID 完全一致**（用 `id sky` 查看），否则挂载共享目录时同样会遇到权限拒绝的问题。
