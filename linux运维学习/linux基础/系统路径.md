简化命令

alias 别名='原命令'
2. 查看别名：输入alias

3. 取消别名：unalias 别名

### 自定义路径到环境变量PATH
export PATH=$PATH:~/bin
- export 将变量导出为**环境变量**
- PATH 系统预设的一个环境变量，里面存储了一系列用冒号（`:`）分隔的目录路径
- **`$PATH`** **引用当前已有的 PATH 变量内容**
- ：追加
- **`~/bin`** `~` 代表当前用户的家目录（例如 `/home/username`），所以 `~/bin` 就是指 `/home/username/bin` 这个目录

在终端直接运行 `export` 命令，只在**当前终端窗口（会话）**有效，一旦关闭终端就失效了。为了让配置永久生效，图片给出了以下步骤：

1. **`   vim ~/.bashrc`**：
    
    - `~/.bashrc` 是 Bash Shell 的配置文件，每次打开一个新的终端窗口时都会自动加载。
        
    - 使用 `vim` 编辑器打开它。
        
2. **添加 export 命令至文件末尾**：
    
    - 在文件最后一行加上 `export PATH=$PATH:~/bin`，保存并退出（在 vim 中按 `Esc`，输入 `:wq` 回车）。
        
3. **`source ~/.bashrc`**：
    
    - `source` 命令用于重新加载配置文件。执行它之后，你刚才的修改会立即在当前终端生效，而不需要关闭并重新打开终端。
