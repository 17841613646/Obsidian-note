### 📚 阶段一：基础层（当前学期 · 打地基）

这个阶段的目标是建立对系统和网络的直觉，你课表里的《操作系统》和《计算机组成原理》是核心支撑。

**[[Linux 系统基础]]**

- **文件系统与权限**：熟练使用 `chmod`、`chown`，理解 Linux 的目录结构。
    
- **用户与组管理**：创建、修改用户，掌握 `sudo` 权限机制。
    
- **进程管理**：使用 `ps`、`top`、`htop`、`kill`、`systemctl` 管理服务和进程。
    
- **包管理**：掌握 `apt`（Debian/Ubuntu）或 `yum/dnf`（RHEL/CentOS）的软件安装与维护。
    
- **文本处理三剑客**：熟练使用 `grep`、`awk`、`sed`，这是日志分析和自动化脚本的基础。
    
- **Shell 脚本编程**：变量、循环、条件判断、函数封装，能编写日志清理、批量初始化等自动化脚本。
    
- **Vim 编辑器**：服务器上必备的文本编辑工具，至少要掌握基本操作。
    
- **SSH 远程管理**：密钥生成、免密登录、端口转发，这是运维日常最频繁的操作。
    
- **日志管理**：`journalctl`、`/var/log`、`tail -f`，学会从日志中定位问题。
    

**[[计算机网络基础]]**

- **OSI 与 TCP/IP 模型**：理解分层结构，重点掌握网络层、传输层和应用层。
    
- **TCP vs UDP**：理解两者的区别和适用场景。
    
- **DNS 原理**：域名解析流程，A/AAAA/CNAME/MX 记录的含义。
    
- **HTTP/HTTPS**：请求方法、状态码、头部字段、TLS 握手过程。
    
- **IP 子网划分与路由**：掌握子网掩码、CIDR、静态路由、NAT 转换。
    
- **VLAN 与交换技术**：理解 VLAN 隔离、单臂路由、ACL 控制。
    
- **抓包分析**：使用 Wireshark 排查网络问题，理解数据包的流动[](https://yun.itheima.com/subject/linuxmap/index.html?cz$aizly$czpc$zx)。
    

**[[编程基础]]**

- **Python 基础**：语法、数据类型、控制流、函数、文件操作。Python 是运维自动化的主流语言。
    
- **Git 版本控制**：`clone`、`commit`、`push`、`branch`、`merge`，这是所有协作和自动化流程的基础。
    

> **本阶段产出**：能独立在虚拟机中安装 CentOS/Ubuntu，搭建 Nginx + MySQL 环境，编写第一个自动化备份脚本。

### ⚙️ 阶段三：自动化与可观测性（大一下至暑假 · 拉开差距）

掌握了容器编排后，你需要让整个系统“自动运转”并“看得见状态”。

- **Terraform**：用 HCL 语言定义和创建云资源（计算、网络、存储），实现环境的可重复构建[](https://m.zpedu.com/it/ityw/37732.html)。
    
- **Ansible**：用 YAML 编写 Playbook，实现服务器配置的批量管理和自动化部署[](https://yun.itheima.com/subject/linuxmap/index.html?cz$aizly$czpc$zx)。
    

**[[CI/CD 与 GitOps]]**

- **ArgoCD / Flux**：GitOps 工具，通过 Git 仓库声明式地管理 K8s 应用部署，这是 2026 年 K8s 交付的主流模式[](https://m.zpedu.com/it/ityw/37732.html)。

> **本阶段产出**：搭建一条完整的 CI/CD 流水线（GitLab CI + Docker + K8s），并配上 Prometheus + Grafana 监控。

### ☁️ 阶段四：云原生与高级阶段（大二 · 面向就业）

**[[Kubernetes（K8s）]]**

- **核心资源**：Pod、Deployment、Service、ConfigMap、Secret、Ingress[](https://m.zpedu.com/it/ityw/37732.html)。
    
- **网络与存储**：CNI 网络插件（如 Calico）、CSI 存储接口[](https://m.zpedu.com/it/ityw/37732.html)。
    
- **调度与弹性**：节点亲和性、资源请求/限制、HPA 自动伸缩[](https://m.zpedu.com/it/ityw/37732.html)。
    
- **安全与管理**：RBAC 权限控制、Network Policy、集群监控[](https://m.zpedu.com/it/ityw/37732.html)。
    
- **服务网格**：Istio 的流量管理、安全策略、可观测性[](https://m.zpedu.com/it/ityw/37732.html)。
    
- **学习周期**：约 3-4 个月，需要大量动手实验[](https://m.zpedu.com/it/ityw/37732.html)。
    

**[[主流云平台]]**

- 选择 **AWS** 或 **阿里云/华为云** 中的一个，深入掌握：VPC 网络、EC2/ECS 计算、IAM 权限、RDS 数据库、负载均衡、对象存储。
    

**安全运维（DevSecOps）**

- **镜像安全**：容器镜像扫描、签名验证。
    
- **运行时安全**：容器运行时监控、安全策略。
    
- **供应链安全**：SBOM（软件物料清单）、依赖漏洞管理。
    

**SRE 实践（高阶方向）**

- **SLI/SLO/SLA**：定义服务水平指标、目标和协议。
    
- **错误预算**：用错误预算平衡稳定性和迭代速度。
    
- **故障演练**：混沌工程，主动注入故障验证系统韧性。
    
- **事件响应**：On-call 轮值、事故复盘、根因分析。
    

**认证加持（可选）**

- **CKA（Kubernetes 管理员认证）**：实操考试，覆盖集群架构、故障排除、工作负载调度、服务网络和存储五大领域[](https://m.zpedu.com/it/ityw/37732.html)。
    

> **本阶段产出**：在云平台上用 Terraform 创建一套 K8s 集群，部署微服务应用，接入完整的监控告警，并通过 GitOps 实现自动发布。
